# UMAI — QA Testing Project

## О проекте
Стажировочный QA-проект по тестированию мобильного приложения UMAI-каталог для подбора детских имён с Django Admin-панелью.
В рамках проекта я тестировала мобильное приложение, API и административную панель, а также сравнивала реализованный функционал и UI/UX с ТЗ и макетами Figma.

## Инструменты
* Postman — API-тестирование
* Swagger — работа с API-документацией
* Android Studio — работа с Android-эмуляторами
* Jira — ведение задач и баг-репортов
* Figma — проверка интерфейса и соответствия макетам

## Что тестировала

### 1. Мобильное приложение
Тестирование проводила на реальном Android-устройстве и эмуляторах Android Studio.
Проверяла:
* список и поиск имён;
* фильтры;
* карточки имён;
* добавление и удаление из «Избранного»;
* функцию «Поделиться»;
* навигацию и кнопку Back;
* локализацию приложения (RU/KG);
* светлую и тёмную темы;
* поведение элементов после пользовательских действий;
* отображение данных после изменений через админ-панель;
* адаптивность интерфейса при изменении размера шрифта и экрана;
* совместимость на Android-устройствах.

### 2. API
Для API-тестирования использовала Postman и Swagger.
Проверяла:
* GET / POST / DELETE запросы;
* статус-коды и тело ответа;
* позитивные и негативные сценарии;
* работу «Избранного»;
* передачу и обработку X-Device-ID;
* последовательность операций с «Избранным»: добавить → проверить → удалить → проверить.

Postman-коллекция: `UMAI API.postman_collection.json`

### 3. Django Admin-панель
Проверяла:
* создание, редактирование и удаление записей;
* работу с именами и их основными полями;
* добавление и удаление записей в «Избранном»;
* отображение данных после изменений в админ-панели;
* права доступа к административным функциям;
* поведение системы после изменения данных через админ-панель.

Отдельно проверяла связь Django Admin → API → мобильное приложение, в том числе ситуации, когда изменения, сделанные в админ-панели, не сразу отображались в мобильном приложении.

## Тестовая документация
В репозитории находятся:

| Файл | Что внутри |

| `mobile_checklist.xlsx` | Чек-лист проверки мобильного приложения |
| `admin_test_cases.xlsx` | Тест-кейсы административной панели |
| `bug_reports.xlsx` | Найденные и оформленные баги |
| `UMAI API.postman_collection.json` | Коллекция запросов Postman |

## Найденные баги
Во время тестирования были найдены проблемы, связанные с:
* интерфейсом;
* навигацией;
* локализацией;
* фильтрами;
* карточками имён;
* «Избранным»;
* отображением данных;
* кэшированием;
* API;
* обработкой некорректных данных.

Найденные проблемы оформлены в `bug_reports.xlsx`.
